# `--dir` Target Flag Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `--dir <path>` to `generate_project_context.js` so the generator can target another project without `cd`.

**Architecture:** `parseArgs` gains a `dir` option (default `'.'`); `main()` resolves it to an absolute path, validates it is an existing directory before any write, and uses it as `root` in place of `process.cwd()`. No other code paths change — everything downstream already threads `root`.

**Tech Stack:** Node.js >= 18, `node:` built-ins only.

**Spec:** `docs/superpowers/specs/2026-07-20-dir-flag-design.md`

## Global Constraints

- Zero npm dependencies; single-file script; no `package.json` in repo root.
- Canonical test command: `node --test` (NEVER `node --test test/` — fails on this Node build). 28 tests currently pass; all must still pass plus the new ones.
- Invalid `--dir` exits 1 with `Directory not found: <path>` on stderr, before ANY filesystem write.
- Commit messages end with: `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`

- [ ] **Step 1: Update existing unit tests and add new ones (RED)**

In `test/unit.test.js`, the two existing `parseArgs` tests use `assert.deepStrictEqual`; add `dir: '.'` to both expected objects. Then append:

```js
test('parseArgs --dir', () => {
  assert.strictEqual(g.parseArgs(['--dir', '/some/place']).dir, '/some/place');
});
```

In `test/generator.test.js`, append (reuse existing `fs`, `path`, `copyFixture`, `runGenerator` imports; add `os` require if not present):

```js
test('--dir targets another project from a different cwd', () => {
  const os = require('node:os');
  const target = copyFixture('expo-app');
  const elsewhere = fs.mkdtempSync(path.join(os.tmpdir(), 'icm-elsewhere-'));
  const r = runGenerator(elsewhere, ['--no-ai', '--dir', target]);
  assert.strictEqual(r.status, 0, r.stderr);
  assert.ok(fs.existsSync(path.join(target, '.context/CONTEXT.md')), '.context created in target');
  assert.ok(!fs.existsSync(path.join(elsewhere, '.context')), 'nothing written to cwd');
});

test('--dir with missing path exits 1 without writes', () => {
  const os = require('node:os');
  const elsewhere = fs.mkdtempSync(path.join(os.tmpdir(), 'icm-elsewhere2-'));
  const r = runGenerator(elsewhere, ['--no-ai', '--dir', path.join(elsewhere, 'nope')]);
  assert.strictEqual(r.status, 1);
  assert.match(r.stderr, /Directory not found/);
  assert.ok(!fs.existsSync(path.join(elsewhere, '.context')), 'no writes on failure');
});
```
